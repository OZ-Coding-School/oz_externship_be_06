# LMS System Flow Overview (for Chatbot Understanding)

이 문서는 오즈코딩스쿨 LMS가
어떤 시스템들로 구성되어 있으며,
사용자의 행동이 시스템 내부에서
어떤 순서와 흐름으로 처리되는지를 설명한다.

이 문서는 “시스템이 어떻게 돌아가는가”에만 집중한다.

---

## 1. LMS의 기본 전제

- LMS는 여러 개의 독립된 시스템으로 구성된다.
- 사용자의 모든 행동은 특정 시스템에 귀속된다.
- 시스템은 서로의 책임을 대신하지 않는다.

---

## 2. 시스템 구성 요소

LMS는 다음 시스템들로 이루어져 있다.

- Accounts  
- Learning Structure  
- Exams  
- QnA  
- Admin System  
- Chatbot  

각 시스템은 고유한 역할을 가진다.

---

## 3. 사용자 진입 흐름 (Entry Flow)

사용자가 LMS에 접근하면
다음 흐름이 먼저 결정된다.

1. 사용자가 LMS에 접근한다.
2. Accounts 시스템을 통해
   사용자 주체가 결정된다.
   (로그인 상태 / 비로그인 상태)

이 시점부터
모든 행동은 “사용자 주체 기준”으로 처리된다.

---

## 4. 학습 관련 기본 흐름 (Learning Flow)

사용자가 학습을 진행할 경우
다음 흐름을 따른다.

1. 사용자는 Learning Structure를 기준으로
   학습 단위에 접근한다.
2. 학습 단위 안에서
   콘텐츠 확인, 참여 등의 행동이 발생한다.
3. 학습 진행 중
   평가가 필요한 경우 Exams 시스템으로 흐름이 이동한다.

Learning Structure는
“학습의 틀”을 제공하고,
Exams는 “평가 처리”를 담당한다.

---

## 5. 평가 흐름 (Exam Flow)

평가가 발생하는 경우
다음 순서로 처리된다.

1. 사용자가 평가에 접근한다.
2. Exams 시스템이 응시 가능 여부를 판단한다.
3. 평가 결과는
   사용자 주체와 연결되어 저장된다.

평가 흐름은
학습 흐름과 연결되지만
독립적인 시스템 책임을 가진다.

---

## 6. 질문 및 문의 흐름 (QnA Flow)

사용자가 질문을 남기는 경우
다음 흐름을 따른다.

1. 사용자가 질문을 등록한다.
2. 질문은 QnA 시스템에 저장된다.
3. 답변은 운영 주체를 통해 제공된다.
4. 사용자는 QnA 시스템을 통해
   답변을 확인한다.

QnA 흐름은
학습 및 평가 흐름과 분리되어 있다.

---

## 7. 운영 및 관리 흐름 (Admin Flow)

운영 관련 작업은
다음 흐름으로 처리된다.

1. 관리자는 Admin System에 접근한다.
2. 사용자, 학습, 평가와 관련된
   관리 작업을 수행한다.
3. 변경 결과는
   각 시스템에 반영된다.

Admin System은
일반 사용자 흐름과 완전히 분리되어 있다.

---

## 8. 보조 시스템 흐름 (Chatbot Position)

Chatbot 시스템은
다른 시스템의 흐름 위에서 동작한다.

- 사용자 행동을 대신하지 않는다.
- 시스템 흐름을 변경하지 않는다.
- 기존 시스템 흐름을 “설명”하기 위해 존재한다.

Chatbot은
LMS의 주 흐름에 영향을 주지 않는다.

---

## 9. 전체 시스템 흐름 요약

LMS의 전체 흐름은 다음과 같이 요약된다.

사용자 진입  
→ 사용자 주체 결정 (Accounts)  
→ 학습 흐름 (Learning Structure)  
→ 평가 흐름 (Exams)  
→ 질문 흐름 (QnA)  
→ 관리 흐름 (Admin System)

각 흐름은
독립적이지만
사용자 주체를 기준으로 연결된다.

---

## 10. 문서의 역할

이 문서는:
- LMS 시스템의 전체 흐름을 설명하는 기준 문서
- 챗봇이 “이 LMS가 어떻게 돌아가는지” 이해하기 위한 문서

이 문서에 없는 흐름은
LMS의 기본 동작으로 가정하지 않는다.
